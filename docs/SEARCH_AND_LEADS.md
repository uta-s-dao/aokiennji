# 北九州・福岡の受注に向けた検索・集客運用

2026-10-20。目的は受注増。優先順位は製作・工事、チャット見積システムの他社導入、商品相談・販売。広告費・有料集客ツールを使わず、既存ドメインの置換に向けて準備する。

## 今回の実装

- `/services` と4つの事業詳細ページで、対応内容・相談時に必要な情報・既存の関連実績・FAQ・担当者への相談を案内する。北九州・福岡を対象にし、地域名だけを差し替えたページの量産はしない。
- `/estimate-system` は他社向けの導入相談窓口。開発済みの機能、担当者確認が必要な流れ、未確定の料金・保守・連携範囲を区別する。
- 商品一覧と詳細は初回HTMLにも公開情報を含める。既存の公開フィルター・価格表示フラグを共通利用する。見つからない・非公開の商品は404を返す。未承認・デモの商品はインデックス対象にせず、サイトマップと商品構造化データからも除外する。
- ページ固有のtitle・description・canonical・OGP、会社・サービス・商品・パンくずの構造化データを追加する。会社情報は既存掲載内容を用い、口コミ・実績件数・営業時間などを創作しない。FAQは表示本文として提供し、リッチリザルトの表示を約束しない。
- ホームの事業カードと会社案内からサービス詳細へ、実績から相談へ接続する。チャットを使う部材相談と、担当者へ直接相談する製作・工事の導線を用意する。
- ホームのスライド画像はNext Imageで配信し、先頭画像をpreloadする。速度の実測値と検索順位は別途本番で確認する。

## 検索公開の設定

`.env.example` を参照。本番を意図せず検索に載せないよう、以下すべてを満たす場合だけ検索公開を許可する。

```dotenv
SITE_URL=https://www.aokieng.co.jp
APP_ORIGIN=https://www.aokieng.co.jp
DEMO_MODE=false
SEARCH_INDEXING_ENABLED=true
```

`NODE_ENV=production` が必須。Vercelでは `VERCEL_ENV=production` も必要。既定は検索非公開。設定はビルド時と起動時に一致させ、変更したら再ビルド・再起動する。SITE_URLは公開用HTTPSオリジンのみ指定できる。wwwの有無は会社・DNS管理者と確定する。管理画面・見積確認・APIには常に `X-Robots-Tag: noindex, nofollow, noarchive` を付け、専用リンクの参照元漏れとキャッシュを抑える。認証・見積トークンによる既存のアクセス制御は引き続き必要。

本番のrobots.txtはAPI以外をクロール可能にし、管理画面・見積確認ページのnoindexを読み取れるようにする。プレビュー・デモは全体をrobots.txtとnoindexヘッダーで検索対象外とし、サイトマップも空にする。robots.txtだけを秘密情報の保護手段にはしない。

## 無料の効果測定

### Search Console

会社管理のGoogleアカウントで既存プロパティの権限を確認し、必要ならDNS所有権確認を行う。HTMLメタタグ確認を使う場合のみ `GOOGLE_SITE_VERIFICATION` を設定する。公開後に `/sitemap.xml` を送信し、ホーム・事業詳細・商品詳細をURL検査する。検索語句、地域を含む相談語句、クリック、表示回数、登録状況を確認する。

### GA4（任意・初期無効）

会社の利用承認と管理アカウント・保存期間を確認後、無料のWebデータストリームを用意する。

```dotenv
ANALYTICS_ENABLED=true
GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

検索公開可能な本番だけで読み込み候補となる。訪問者がページ末尾で分析に同意するまで、Googleのスクリプトを読み込まない。撤回で計測を停止し、当該サイトのGA Cookieを削除する。同意状態は同じブラウザーに保存し、保存できない場合は当該訪問中のみ有効。広告関連の保存とパーソナライズは無効にする。

**ストリームの拡張計測機能はすべてOFFにする。** 自動フォーム・自動履歴変更・検索語・外部リンク計測などを併用しない。氏名・メール・フォーム本文・チャット本文・見積トークン・受付番号をイベントに含めず、URLは公開ページのパスだけに正規化する。クエリー文字列と参照元は送らない。商品詳細の計測パスは `/products/item` にまとめる。管理・見積確認・APIは計測対象外。GA4はIPアドレス等の通信情報を処理するため、個人情報が一切外部送信されないという案内はしない。

| イベント        | 発生条件                        | 用途                                        |
| --------------- | ------------------------------- | ------------------------------------------- |
| `page_view`     | 同意後の公開ページ閲覧          | 入口と閲覧経路                              |
| `contact_click` | 電話リンクをクリック            | 電話への関心。実際の通話成立・受注とは別    |
| `chat_open`     | チャットを開く                  | 相談開始への関心                            |
| `generate_lead` | 問い合わせ・見積依頼APIの成功後 | 受付完了。`lead_type` でinquiry/quoteを区別 |

`generate_lead` をキーイベントに設定し、DebugView・リアルタイムで検証する。失敗・ボタンクリックだけでは受付完了と数えない。実際の受注は担当者が成約・失注・案件金額を確認して集計する。自動で受注したとは判定しない。Web解析と受注台帳の自動照合は今回の範囲外。

## Googleマップ（MEO）

サイト変更だけでGoogleビジネスプロフィールの変更は完了しない。Q019で既存プロフィールと管理権限を確認し、次の内容を会社管理者が整備する。重複プロフィールは作らない。

1. 正式社名は「アオキエンジ株式会社」のままにし、検索語や地域名を付け足さない。
2. 住所・電話は会社案内と一致させる。営業時間・来訪受付・サービス地域は会社確認後に設定する。
3. 主カテゴリ・追加カテゴリは実態に一致する選択肢を選び、事業詳細ページへのリンクと提供サービスを登録する。
4. 承認済みの設備・製作物・現場写真を追加し、実績の内容が分かる説明を付ける。
5. 実際のお客様に率直な口コミを依頼し、担当者が返信する。特典、架空の口コミ、高評価者だけの選別は行わない。
6. 表示・電話等の操作・問い合わせ・受注を月単位で確認する。

所在地・距離は操作できる要素ではないため、福岡全域で地図順位を保証しない。
