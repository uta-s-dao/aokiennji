# 未登録商品の販売概算（2026-10-15）

未登録商品の調達候補を確認した後、必要数量・配送先と確認済みの仕入条件から、販売単価・送料・税込合計・納期目安をチャットで案内する機能を追加した。

## 設定と運用

1. 管理画面の「設定 → 未登録商品の販売概算」で、原価への上乗せ率、案件あたり最低利益、手配料、単価の切り上げ単位、直送／当社経由、追加営業日を設定する。都道府県別の請求送料と概算の有効時間も設定できる。上乗せ率は粗利率ではない。
2. 「チャットの履歴 → 会話 → AI調査メモ → 販売概算用の調達条件」で、候補ごとの仕入可能価格、税区分・税率、入数、調達可能数量、配送先、送料、お客様への到着までの営業日数を確認する。出典URLと取得日時を表示する。Web掲載価格は初期入力であり、販売価格として公開しない。
3. 調達先・入力条件を確認した担当者が確認済みとして保存する。未入力は未確認のままで、無料・即納・在庫ありとは解釈しない。配送条件は確認した都道府県にだけ適用する。
4. 概算機能を有効にし、Web検索・価格表示・納期表示も有効にする。お客様が数量・届け先を伝え、条件が揃えば、次の質問から概算を返す。正式見積と注文は既存の受付手順で確定する。

商業条件は現時点で未決定のため、3212番では概算機能は無効・上乗せ率などは空欄のまま。試験用の率や送料を実際の販売設定として保存していない。価格だけを取得して送料・納期を作る機能ではなく、候補ごとの担当者確認が必要。継続的な自動取得には、承認済み仕入先の価格・在庫・配送データ連携が次の拡張になる。

## 計算と表示

- 税込仕入価格は仕入時の税率で税抜換算し、商品原価の総額を円単位で切り上げる。
- 当社経由なら仕入先から当社への送料を商品原価に含める。
- `max(商品原価 × (1 + 上乗せ率), 商品原価 + 最低利益) + 手配料` を数量で割り、設定単位で単価を切り上げる。金額は整数演算する。
- 税抜商品小計と税抜請求送料を合算して販売時の税率を適用し、消費税額は円未満切り捨て。
- 数量が販売単位の入数の倍数でない場合は、数量を確認する。調達可能数量が足りない場合も概算を出さない。
- 納期は「ご注文確定後○～○営業日でお届け」と表示。仕入先・配送会社の営業日を担当者が確認する。特定の到着日を休日計算で作らない。
- 複数の候補の価格・送料・納期を混ぜない。完全な条件がある候補から合計の小さい概算を選ぶ。
- 仕入価格、仕入先URL、利益率、内部の更新判定値はお客様のAPI・画面には返さない。
- 数量の変更は再計算し、別型番では前の数量・配送先を流用しない。見積依頼フォームに数量と概算明細を引き継ぐ。
- 条件・表示権限の変更や有効期限切れでは、公開履歴の概算・引継ぎ文・会話要約も再確認表示にする。管理画面の元の会話本文は保持する。

## 動作例（架空の条件による試験）

実売価格の提案ではない。試験用の仕入単位1個・税込1,100円・仕入税率10%、調達可能20個、上乗せ20%、最低利益0円、手配料0円、単価10円単位切り上げ、請求送料税抜800円、配送2～3営業日＋追加1営業日の場合：

お客様：B-300-SCIを10個、大阪までの価格と納期を教えてください

回答：

```text
「B-300-SCI」10個・大阪へのお届けの概算です。
販売単価（税抜）：1,200円
商品小計（税抜）：12,000円
送料（税抜）：800円
消費税（10%）：1,280円
合計（税込）：14,080円
納期目安：ご注文確定後 3～4営業日でお届け
（金額の有効期限と、注文前の在庫・配送条件再確認を表示）
```

試験用の価格・在庫・送料・日数は架空。B-300-SCIの実際の販売条件を保証するものではない。
