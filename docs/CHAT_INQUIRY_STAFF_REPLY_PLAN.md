# 商品相談の社員回答を同じチャットへ返す別計画

今回の改修は、商品特定と既存の商品・調達照会への接続まで。以下は未実装の別計画であり、承認・公開済みではない。

## 現在の境界

- 顧客会話、登録商品・登録在庫、調達メモと承認、見積依頼、正式見積発行は既存機能。
- 社員が取扱可否・現在在庫・確保数量の確認結果を書き、顧客向けに承認し、同じ会話で顧客が読む一連の操作は未実装。
- したがって問い合わせ未送信の段階では「社内で確認中」「受付済み」と案内しない。画像は会話所有者と管理者認証済み社員が参照できる。

## 実装案と受入条件

1. 照会案件を会話・対象メーカー／型番・数量に関連付け、受付／担当中／回答準備／回答済みを管理する。型番訂正時は旧商品の回答を新商品へ適用しない。
2. 社員向け回答フォームに、販売・調達可否、自社在庫、仕入先掲載在庫、確保済み数量を別項目で置く。確認日時・確認者・根拠・有効期限・顧客公開文を記録する。社内仕入先・仕入価格は顧客公開しない。
3. 下書きと公開を分離し、権限者の明示操作で署名付き社員メッセージを会話へ追加する。改訂履歴と取り消しを残す。AIの返信・正式見積・注文承認とは区別する。
4. 顧客は現在の所有者セッションで再閲覧できる。別端末への本人確認と復帰方法、通知手段を決めてから追加する。匿名URLだけで画像・会話を公開しない。
5. 二重送信・同時編集・古い型番・期限切れ・担当者不在・通知失敗を検証する。他人の会話／画像へのアクセスを拒否し、通知送信と閲覧可能になった事実を区別する。

## 会社確認との対応

新しい質問番号は作らず、既存の `COMPANY_QUESTIONS.md` を参照する。

- Q007：確認担当、新しい仕入先の利用条件、在庫情報源・更新頻度。
- Q008：概算／正式見積と承認・送付の範囲。本機能の在庫回答を正式見積として扱わない。
- Q009：問い合わせの担当・代行・通知先・回答目安・未確認時の引継ぎ。見積を希望しない商品照会も対象になる。
- Q016・Q018：写真を含む個人情報・外部AI・保存期間、運用・復旧。今回の画像上限は技術的な防御値であり、会社承認済みの保管方針ではない。

これらは既存の未回答事項に含まれるため、今回質問票の重複追記・別Sites作成はしない。上記の回答欄と既存HTTPS質問票を会社への確認時に使う。
