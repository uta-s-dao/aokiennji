# 社員向けサイト編集

税込38万円の基本プラン（サイト制作18万円＋AI相談チャット20万円）に含む編集機能。2026-10-20、本チャットで範囲と実装計画の承認を受けて追加。

## 操作

1. 既存の管理者ログイン後、管理画面の「サイト編集」（`/admin?tab=site-content`）を開く。
2. トップページの見出し・強調部分・紹介文・事業紹介文・メイン写真3枚、お知らせ、製作実績を編集する。実績には写真・カテゴリ・説明・表示順がある。
3. 「下書き保存」。この時点では一般公開されない。
4. 「プレビュー」で保存内容をPC・スマートフォン幅で確認する。プレビューはログイン済み管理者のみ閲覧可能。
5. 「公開する」→「この内容を公開」。トップ・お知らせ・実績の保存済み編集をまとめて反映する。

お知らせは掲載日の新しい順。公開対象の実績の先頭3件をトップページへ表示する。公開対象チェックを外した項目は非表示。「削除」も下書きへの操作なので、公開するまでは公開サイトに残る。予約投稿ではなく手動公開。

フォームの入力中は自動保存しない。保存後に別の編集項目へ移るか、管理画面を閉じる。未保存で別メニューへ移動・ログアウト・ページを閉じる際は警告する。他の画面で更新された場合は409で拒否し、入力を自動上書きしない。競合時は入力を控えてから再読み込みする。

## 写真・公開範囲

- JPEG・PNG・WebP、入力5MB以下・2,500万画素以下。サーバー側で実画像を読取り、向きを補正、長辺1,920px以内のWebPへ再生成し、元のメタデータを除去する。SVG・アニメーションは受け付けない。
- アップロードした写真は下書き用として保存。一般公開用の画像URLも、公開対象の公開データがその画像を使うまでは404。非公開にして再公開すると一般公開用URLも404に戻る。ただし既に閲覧・保存された画像を取り消すものではない。
- 外部URLや任意ファイルパスは画像欄に保存できない。既存の公開写真またはこの機能でアップロードした写真を使用する。
- 画像の合計保存上限は100MB。未使用のアップロード画像も残るため、運用担当者がバックアップと参照状況を確認して整理する。自動削除は行わない。
- 内容はHTMLとして解釈せずテキスト表示する。社員によるレイアウト変更機能は設けていない。

## 保存・認証・本番導入

現在のアプリのSQLiteに、`site_content`（下書き・公開スナップショット・リビジョン・公開日時）と`site_images`（再生成した写真のBLOB）を追加する。既存データを削除せず、初回に現在のサイト内容を初期値として登録する。DBのバックアップに写真も含まれる。APIは既存の管理者認証・Origin検証を使用し、保存・公開・写真登録を操作履歴へ記録する。社員別アカウントや編集専用の権限分離は今回追加していない。

本番Supabaseへのアプリ移行は別作業。移行時にはこの2テーブルと画像データ・公開参照の制御も移す必要がある。この機能を追加しただけで本番Supabaseへ保存されるわけではない。Vercelの一時ディスクを使うデモ環境では永続保存を保証しない。公開ページは動的に公開スナップショットを読み、下書きAPIは認証必須・no-store。

プレビューは`/admin/site-preview`のみ同じオリジンのiframeへ埋込み可能（SAMEORIGIN、`frame-ancestors 'self'`）。管理者認証と検索除外を維持する。

月額保守、外部サービス実費、発行者名、納期・支払条件は未確定のまま。サイト編集追加による初期費用の増額はない。見積書は`docs/estimates/2026-10-20/`のドラフトを参照。

## 検証

保存の分離、DB再接続後の永続性、競合拒否、公開画像の参照制御、画像形式と容量、管理者認証、Origin検証を`tests/site-content.test.ts`で確認。`tests/e2e/site-content.spec.ts`でPC・モバイルの編集・写真アップロード・下書き・プレビュー・公開・非公開を確認する。実際の実行結果は完了報告に記載する。

2026-10-20の実行結果：関連テスト7件成功、PC・モバイルの編集操作2ケース成功、既存公開導線の回帰8ケース成功、`npm run typecheck`と`NEXT_DIST_DIR=.next-build npm run build`成功、`git diff --check`成功。ブラウザー検証には独立した一時DBを使用し、外部AI・メール送信・実注文を無効化。画像のデコード完了を待って表示を検証する。スクリーンショットは`docs/screenshots/site-content-*.png`（検証用データ）。本番公開やSupabaseへのアプリ移行は行っていない。
