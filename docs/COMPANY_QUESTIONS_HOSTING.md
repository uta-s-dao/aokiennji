## 回答・メモの入力

各質問の「回答・メモ」欄へ直接入力できる。「会社に確認済みの回答」は、実際に会社へ確認した項目だけチェックする。未確認のメモも記入できる。

- 入力内容は同じブラウザーに自動保存し、再読み込み後も復元する。他の端末との同期や、サーバーへの回答保存は行わない。
- 「回答メモをダウンロード」で、質問番号・質問文・回答・確認状況を含むMarkdownファイルを書き出す。このチャットへ添付すれば、回答を質問票や設定へ反映する作業に使える。
- 「回答メモをコピー」で同じ内容をコピーできる。コピー機能が使えない場合は、選択可能なメモを表示する。
- ブラウザー保存が使えない場合も、入力とダウンロードは利用できる。保存失敗は画面に表示する。
- 印刷・PDF保存には、長い回答も含めて反映する。

ブラウザーの保存キーはSite IDと質問番号を基準にしている。追記・再掲載で既存の回答が消えないよう、保存キーや質問番号を変更しない。

## 更新の原則

質問の原稿は `docs/COMPANY_QUESTIONS.md` に集約する。新しい会社確認事項が出たら同じ原稿へ追記し、質問番号を維持する。ユーザーへ都度質問せず、最後にまとめて会社に確認する。

HTTPS版はこのSiteを更新する。別のSiteやURLを作り直さない。閲覧範囲は、ユーザーから変更の指定があるまで本人限定を維持する。

1. Sitesスキルを読み、上記Site IDの現状と閲覧範囲を取得する。同じSiteのソース用認証を取得し、ソースヘルパーでチェックアウトを開く。認証トークンはファイルやログへ保存しない。

   ```bash
   node scripts/build-company-questions-site.mjs .data/sites/company-questions/dist https://aoki-company-questions.sandystork2.chatgpt.site
   ```
